# IBM Customer Churn Analysis & Dashboards

This directory contains Databricks Lakeview dashboards and SQL query notebooks for IBM Telco Customer Churn:
- **`IBM_Customer_Churn_Enhanced_Dashboard.lvdash.json`**: Databricks Lakeview dashboard definition with KPI cards and breakdowns.
- **`SQL Queries.dbquery.ipynb`**: Segment churn analysis, contract, payment method, internet service, and tenure queries.
