# TRAI Telecom Industry Dashboards & SQL Queries

This directory contains Databricks Lakeview dashboards and SQL query notebooks for TRAI India Telecom Analytics:
- **`TRAI_Telecom_Consolidated_Dashboard.lvdash.json`**: Consolidated Databricks Lakeview dashboard definition.
- **`TRAI Overview Analysis.dbquery.ipynb`**: Headline MNP, ARPU, and prepaid share queries.
- **`Average ARPU Analysis.dbquery.ipynb`**: Circle-wise ARPU analysis.
- **`Porting Requests by LSA.dbquery.ipynb`**: MNP requests by service area.
- **`Porting Requests by Reporting Month.dbquery.ipynb`**: MoM porting trends.
- **`Porting Requests by Zone.dbquery.ipynb`**: Zone I vs Zone II porting breakdown.
- **`Prepaid Percentage Analysis.dbquery.ipynb`**: Prepaid vs postpaid subscriber mix.
- **`Porting Data Validation.dbquery.ipynb`**: Data quality checks.
