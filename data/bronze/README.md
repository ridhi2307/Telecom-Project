# Bronze Raw Data Layer

Raw datasets ingested from primary telecom sources:
- **`ibm_telco/`**: IBM Telco Customer Churn dataset (7,043 customer accounts).
- **`trai_qos/`**: TRAI QoS June 2026 dataset (88 rows across 5 operators and 22 circles).
- **`trai_subscribers/`**: Subscriber base, net additions, wireless/fixed broadband, and MNP status.
- **`trai_usage/`**: Circle-wise usage metrics and quarterly wireless trends.
